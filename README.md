# 🐶 Generador de Perros Aleatorios

Esta es una aplicación web sencilla que utiliza una API pública para mostrar imágenes aleatorias de perros. Es mi primer proyecto conectando **HTML, JavaScript y APIs externas**.

## 🚀 Funcionalidades
* Muestra una imagen de un perro al azar al cargar la página.
* Tiene un botón para actualizar la imagen sin recargar la web.
* Utiliza la [Dog API](https://dog.ceo/dog-api/).

## 🛠️ Tecnologías utilizadas
* **HTML5**: Estructura de la página.
* **JavaScript (Fetch API)**: Para realizar la consulta al servidor.
* **CSS**: Para dar un estilo básico y limpio.
